# ✨ DecodeLabs Project 2 — AI Copywriter & Tone Transformer

An AI-powered **Automated Copywriting and Tone Transformation application** built using **Python, Streamlit, and Google Gemini**.

The application generates professional, platform-specific marketing copy from product information and can also transform existing content into different tones and styles.

---

## 🚀 Project Overview

Businesses and content creators often need to adapt the same product information for different platforms, audiences, and brand voices.

This project provides an AI-powered solution that can:

- Generate marketing copy from a product description
- Adapt content for different platforms
- Control the tone and brand voice
- Generate multiple copy variations
- Transform existing marketing content into a different tone
- Control AI creativity using Temperature and Top_P
- Validate generated content using character and word counts
- Maintain generation history during the session
- Download generated content as `.txt` files

The project uses **Google Gemini API** for content generation and **Streamlit** for the interactive web interface.

---

## 🎯 Objectives

The main objectives of this project are:

1. Automate marketing copy generation.
2. Create platform-specific content.
3. Provide flexible tone transformation.
4. Use dynamic prompt templates instead of hard-coded prompts.
5. Experiment with AI inference parameters.
6. Provide a user-friendly interface for non-technical users.
7. Demonstrate practical Generative AI orchestration.
